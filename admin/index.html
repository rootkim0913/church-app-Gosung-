썸네일 제작

사진을 올리지 않아도 상품명으로 웹 참고 이미지를 자동 검색할 수 있습니다.

상용화 안전 규칙: Google 이미지 임의 복사는 사용하지 않습니다. 현재 자동검색은 Openverse의 상업 이용·수정 가능 라이선스 필터를 사용하며, 최종 사용 전 원 출처/라이선스를 확인해야 합니다. 실제 최종 AI 생성은 OpenAI API 연결 후 활성화합니다.

사진이 없으면 상품명으로 공개 라이선스 이미지를 찾습니다.

상세페이지 제작

사진 없이도 상품명으로 참고 이미지를 자동 검색한 뒤 동일 상품 이미지를 6개 섹션에 일관되게 사용합니다.

웹 사진은 참고 소스로만 취급하고 출처·라이선스를 함께 표시합니다. 실제 판매용 최종 결과는 OpenAI 이미지 API 연결 후 기존 상세페이지 마스터 프롬프트를 그대로 사용해 새 이미지로 생성하는 방식이 가장 안전합니다.

쿠팡 상품등록 준비

관리자 검수 후 실제 API를 실행하는 구조입니다.

현재는 데모입니다. 실제 Vendor ID / Access Key / Secret Key는 입력하지 않습니다.

ChatGPT 수정 요청

관리자 사이트 안에서 수정할 내용을 정리하고, 그대로 ChatGPT에 전달할 수 있습니다.

현재는 무료·안전 방식입니다. OpenAI API를 직접 연결하지 않고 요청문을 자동 생성한 뒤 복사해서 ChatGPT를 엽니다. API 키·개인정보는 이 칸에 입력하지 마세요.

임시저장은 이 브라우저의 localStorage에만 저장됩니다. API 키·개인정보는 저장하지 마세요.

ChatGPT에 보낼 요청문

왼쪽에 수정 내용을 입력하고 “요청문 만들기”를 눌러주세요.

ChatGPT가 열리면 복사된 요청문을 붙여넣으면 됩니다. 이 프로젝트는 GitHub → Render 자동배포 구조라 수정 후 다시 같은 URL에 반영할 수 있습니다.

프로젝트 브레인

ChatGPT 계정이나 컴퓨터가 바뀌어도 Miracle smart의 기준을 잃지 않도록 프로젝트 컨텍스트를 사이트 자체에 보관합니다.

중요: 다른 ChatGPT 계정은 이전 대화 기억을 자동으로 이어받지 않습니다. 대신 아래 프로젝트 브레인을 복사해서 새 ChatGPT에 전달하면 현재 구조·규칙·배포주소·미완성 작업을 그대로 인계할 수 있습니다. 이 파일에는 API Secret이나 고객 개인정보를 넣지 않습니다.
