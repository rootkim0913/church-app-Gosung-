썸네일 제작

03

상세페이지 제작

상품명·문의전화·문의시간을 기준으로 6개 섹션을 제작합니다.

04

쿠팡 상품등록

회원별 Open API 설정 후 검수된 상품을 등록합니다.

제작 요청

고객은 요청만 남기고, 실제 생성·검수·등록은 관리자 사이트에서 처리하는 구조입니다.

현재 공개 데모에서는 입력 내용과 사진을 외부로 전송하거나 저장하지 않습니다. 실제 개인정보·API 키는 입력하지 마세요.

사진이 없어도 상품명만으로 요청할 수 있습니다. 운영자가 상업 이용 가능한 웹 참고 이미지 또는 AI 생성 방식으로 제작합니다.

내 계정

운영 전 데모입니다. 실제 키는 입력하지 마세요.

실제 개인정보·Access Key·Secret Key를 입력하지 마세요. 현재 화면은 저장/전송하지 않습니다.

고객 도착 보장일이 아니라 출고 예정 리드타임입니다.

회원별 쿠팡 연동 체크리스트

필수 · 회원 준비

  • WING에서 OPEN API 용도로 키 발급
  • Vendor ID
  • Access Key
  • Secret Key
  • WING 실사용자 ID
  • 운영 서버 IP Allowlist 등록

배송 · 운영 기본값

  • 택배사 코드
  • 출고지 코드
  • 반품지 코드/명/연락처/주소
  • 배송비·반품배송비
  • 도서산간 여부
  • 출고 소요일 1~7일

자동 처리

  • HMAC-SHA256 서명
  • 카테고리 코드 조회/검증
  • vendorItemId 저장
  • 쿠폰 requestedId / contractId
  • 재고 자동유지 스케줄러

외부 결제 링크

현재 비활성화. 나중에 PAYMENT_URL 하나만 넣어 결제 페이지로 이동하도록 연결합니다.

현재 공개 데모는 외부 API·결제·개인정보 저장을 사용하지 않습니다.
