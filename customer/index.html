제작 요청

고객은 요청만 남기고, 실제 생성·검수·등록은 관리자 사이트에서 처리하는 구조입니다.

현재 공개 데모에서는 입력 내용과 사진을 외부로 전송하거나 저장하지 않습니다. 실제 개인정보·API 키는 입력하지 마세요.

사진이 없어도 상품명만으로 요청할 수 있습니다. 운영자가 상업 이용 가능한 웹 참고 이미지 또는 AI 생성 방식으로 제작합니다.

이미 회원인가요?

인증센터

회원가입은 간단하게 끝내고, 쿠팡 판매에 필요한 설정은 여기서 단계별로 연결합니다.

현재는 데모 화면입니다. 실제 Access Key / Secret Key는 입력하지 마세요. 실서비스에서는 서버 암호화 저장과 권한 분리를 적용합니다.
